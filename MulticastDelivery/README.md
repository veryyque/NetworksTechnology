# Multicast Delivery

Лабораторная работа по дисциплине **«Сетевые технологии»**.

## Описание

Приложение обнаруживает другие запущенные копии самого себя в локальной сети с помощью multicast UDP.

Программа отслеживает появление и исчезновение других экземпляров приложения и при изменении состава участников выводит список IP-адресов активных копий.

Адрес multicast-группы передаётся программе через аргумент командной строки.

Приложение поддерживает работу как с IPv4, так и с IPv6 и автоматически выбирает нужный протокол в зависимости от переданного адреса multicast-группы.

## Запуск

```bash
swift run MulticastDelivery <multicast-address>
```

Пример:

```bash
swift run MulticastDelivery 239.255.0.1
```

Для проверки работы необходимо запустить несколько экземпляров программы с одинаковым multicast-адресом.
